**Ứng dụng AI, phân tích thiết kế, lập kế hoạch và triển khai sản phẩm game sau**

•	Thể loại Game quy định:  Idle Game (Game treo máy / tự vận hành 1 màn hình)

•	Định dạng màn hình:  Game phát triển gọn gàng trong 1 màn hình duy nhất (Single-screen Incremental Game).

•	Vòng lặp Core Loop:  Tập trung vào cơ chế Tap/Click thu thập tài nguyên -> Tự động hóa sản xuất (Passive Generator) -> Nâng cấp chỉ số lũy tiến (Exponential Upgrades) -> Mở khóa mốc phần thưởng.

•	Ứng dụng AI:  Sinh viên được khuyến khích công khai sử dụng các công cụ AI (Midjourney, Stable Diffusion, Recraft, Suno, ChatGPT, Claude, Gemini, ...) để tạo tài nguyên. Cần thể hiện quy trình dùng AI trong báo cáo.

•	Cắt giảm tính năng bên lề:  Sản phẩm LOẠI BỎ toàn bộ các tính năng phụ trợ như: Đăng ký/Đăng nhập tài khoản, Lưu Cloud Backend, Quảng cáo (Ads), Cửa hàng nạp tiền (IAP). Game chơi trực tiếp Offline hoặc Local storage.
